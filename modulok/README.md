# modulok/

A fejezetoldalak nem külön HTML-fájlok: egyetlen közös sablon (`js/views/chapter.js`) rendereli őket a `data/tartalom/*.json` tartalmából.

A címek így néznek ki: `index.html#/m/m01` (modul), `index.html#/m/m01/f/1.2` (fejezet), `index.html#/m/m01/zaro` (modulzáró).

A tartalom szerkesztéséről lásd a fő `README.md` 4. pontját.
